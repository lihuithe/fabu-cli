# Agent 使用教程

直接把下面这几段话复制发给 Codex、Cursor 或其他 Agent 即可安装使用。

## 安装提示词

```
你给我把 https://github.com/lihuithe/fabu-cli 这个项目拉到本地来安装一下，然后封装成 skill，未来我需要你使用这个发布 skill 给我做视频或者图文发布
```

安装完成后，Agent 应在本机具备：

- 已克隆并安装依赖的 `fabu-cli` 项目目录
- 已写入个人 Skill 目录（如 `~/.codex/skills/fabu-cli/` 或 `~/.cursor/skills/fabu-cli/`）的发布 Skill，其中记录本机项目绝对路径
- 能通过 `node <项目路径>/bin/fabu.js doctor --json` 通过环境检查

本仓库已提供 Skill 模板，安装时可复制 `skills/fabu-cli/` 到个人 Skill 目录，并把其中的项目路径改成实际克隆位置。

## 使用提示词

### 1. 绑定抖音号

```
你用发布 skill 给我绑定一下抖音号
```

### 2. 批量定时发布

```
你给我把这批视频发到我的抖音、视频号、快手、B站账号上，每天发3条，早中晚时间你自己定，设置定时发布，需要勾原创，不需要做声明
```

### 3. 更新视频号授权

视频号授权一般只能保持 24 小时。

```
发布 skill 我需要更新一下视频号的绑定授权
```

### 4. 新增抖音号绑定

```
发布 skill 你给我新增一个抖音号的绑定
```

## 补充说明

- 当前支持平台：抖音、快手、视频号、B站；不支持小红书。
- 账号绑定会打开 Chrome，需你在窗口内完成扫码或登录；Agent 不会代填密码或验证码。
- 定时发布是各平台内的预约发表时间，不是到点才启动本机浏览器。
- 视频号 `original: true` 表示勾选原创；不填 `declaration` 即不做作者声明。
- 若 Agent 报告 `submission_unknown`，先按 Skill 指引核实，不要直接重复提交。
